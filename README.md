# Attat Hair Salon

The website for Attat Hair Salon, a Nigerian hair salon business. Customers can browse services and prices, book an appointment online, and chat with the salon on WhatsApp, either with staff or with an automated assistant that answers common questions and helps them book.

> **Status:** Planning. See the [Product Requirements Document](docs/PRD.md).

## Features (planned)

- **Services and price list**: braids, cornrows, weaves, wig installs, locs, relaxers, natural hair care and kids' styles, with prices in Naira (₦) and how long each takes.
- **Online booking**: pick a service, a stylist and a time slot, then confirm. An optional deposit can be paid through Paystack or Flutterwave.
- **WhatsApp assistance**:
  - "Chat on WhatsApp" buttons on every page (click-to-chat)
  - An automated WhatsApp assistant for FAQs, prices, opening hours, directions and booking
  - Booking confirmations and reminders sent on WhatsApp
- **Style gallery**: photos of finished work, grouped by style.
- **Salon admin**: manage bookings, services, prices, stylists and opening hours.
- **Mobile-first and light on data**: built for phones on Nigerian mobile networks.
